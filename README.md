# cafe
Fazendo café

Ingredientes:
- cafe
-xicara
-filtro
-agua quente
-leite
-açucar 
-canela
-chocolate

Preparação:
Pegue o grão do café
mõe o grão do café
coloque o grão na cafeteira
coloque a água quente na cafeteira
ligue a cafeteira
bata o leite e o açucar 
adicione o leite batido ao café
adicione a canela em cima 
beba o café hehe 



Bom café!
